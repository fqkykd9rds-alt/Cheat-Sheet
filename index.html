CSS Box Model Reference

Content Area CSS Properties

CSS Property Property name Description
box-sizing: Box sizing Sets how the total width and height of an element is calculated
width: Width Sets the total width of an element
min-width: Minimum Width Sets the minimum width of an element
max-width: Maximum width Sets the maximum width of an element
height: height Specifies the height of an element
min-height: Minimum height Sets the minimum height of an element
max-height: Maximum height Sets the maximum height of an element

Padding Area CSS Properties

CSS Property Property name Description
padding-top: Top padding Sets the height of the padding area on the top of an element
padding-right: Right padding Sets the width of the padding area on the right of an element
padding-bottom: Bottom padding Sets the height of the padding area on the bottom of an element
padding-left: Left padding Sets the width of the padding area on the left of an element
padding: Padding Sets the padding of an element on all sides

Border Area CSS Properties

CSS Property Property name Description
border-style Border style
border-width Border width
border-color Border color
border Border

Margin Area CSS Properties

CSS Property Property name Description
margin-top Top margin
margin-right Right margin
margin-bottom Bottom margin
margin-left Left margin
margin Margin
